# Аудит исходной версии и принятые решения

Ревизия выполнена 24 ноября 2026. База приложения — `archive/2026-11-24/dev` (`6daafbf`); main — `27d9020`. Просмотрены все восемь веток, их история/отличия, исходники клиентских маршрутов и серверных обработчиков, все модели и миграции, package/lock/env-файлы, открытые PR и доступные check runs. [Таблица веток](BRANCHING.md).

## Подтверждённые проблемы

| Область | Было | Исправление |
|---|---|---|
| Git | Код в dev, документация в main, уникальный footer отдельно | Архивные теги всех голов, merge истории, develop и release через PR |
| Сборка | CRA, старое дерево зависимостей, раздельные lock-файлы | React 19/Vite 8, npm workspaces и один lock |
| Сессии | authRouter подключался раньше session middleware | Порядок middleware исправлен; PostgreSQL session store |
| Вход | SignIn показывала форму без запроса входа | API login/logout/session и подключённые формы |
| Регистрация | Жёсткий localhost URL, отдельное несогласованное auth-состояние | Относительный API, CSRF, серверная сессия, единый AuthProvider |
| Навигация | Главная/«О нас» не были подключены; профиль — заготовка | Реальные Route, формы, 404, адаптивное меню |
| Данные | Старые связи профилей допускали неоднозначность; обязательные даты мешали созданию профиля | Один профиль на пользователя, nullable даты, отдельная миграция |
| Конфигурация БД | Разные dialect-настройки dev/test/production, старые тестовые MySQL значения | PostgreSQL URL из environment во всех средах |
| Чат | `src/index.js` искал `./ws`, файл лежал выше; незавершённые Message/sender/receiver, ошибочная обработка событий, нет авторизации | Единый HTTP/WS runtime, таблица Messages, session auth и приватная история |
| UI чата | Фиктивные сообщения и несвязанный сценарий | Реальный контакт по ID, двусторонняя отправка и перезагрузка истории |
| Тесты | Backend `npm test` намеренно завершался кодом 1 | Unit, React, PostgreSQL/WS/migrations, Playwright/axe |
| Команды БД | Были destructive drop-последовательности | Явные migrate/seed, отдельная `_test` БД и временные схемы |

## Команды исходного состояния

Backend `npm test` действительно вернул 1 с текстом заглушки. Попытка frontend build до установки старых зависимостей завершилась отсутствием `react-scripts`, запуск backend — отсутствием `dotenv`. Эти две ошибки подтверждают неполную локальную среду, но сами по себе не доказывают несовместимость старой сборки. Всё старое дерево зависимостей ради такой проверки не устанавливалось. Подтверждение логических дефектов основано на исходниках; результаты новой воспроизводимой установки и приёмки вынесены в [TESTING](TESTING.md).
