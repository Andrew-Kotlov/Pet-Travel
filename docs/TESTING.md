## Что именно покрыто

Unit API: обязательная конфигурация, production HTTPS origins, ограничения proxy, закрытый набор ролей/полей, нормализация email, длина bcrypt-пароля в UTF-8, типы и границы питомцев/ID/сообщений, исключение приватных полей пользователя.

React: девять статей по старым URL, главная, реальная фильтрация/пустая выдача, регистрация ситтера, ошибка входа, защита профиля, ошибка восстановления сессии и retry, 404, мобильное меню, единственный начальный запрос сессии в StrictMode.

PostgreSQL/API/WS: реальная миграция новой схемы, повторное применение, уникальные/FK/check constraints, CSRF и неверный Origin (включая Unicode-токен), регистрация с ротацией сессии и bcrypt, duplicate email, неверный вход, обе роли профиля, CRUD питомца и запрет чужих данных, приватная история, авторизованный WS, malformed JSON/подмена отправителя, онлайн/офлайн доставка, seed, restart, отзыв сессии получателя без утечки сообщений, logout закрывает WS, занятый порт, readiness 503 при недоступной таблице.

Отдельный migration test создаёт восемь исходных миграций, добавляет вымышленные старые записи и конфликт email. Девятая миграция откатывается полностью. После удаления **только созданного тестом дубликата** обновление сохраняет пользователя, профиль и питомца; старые обязательные даты становятся nullable. Работающая/неизвестная база не удалялась.

Браузер: два независимых пользователя проходят регистрацию, создание обоих профилей, CRUD питомца, диалог в обе стороны, reload с восстановлением истории, выход/вход. Дополнительно восемь публичных маршрутов проверены на 360, 768 и 1280 px: один h1, загруженные фото, отсутствие горизонтального overflow. Все девять статей открываются напрямую. Skip link работает с Tab/Enter.

axe проверил WCAG 2 A/AA и 2.1 AA: главную, вход, регистрацию и статью `/cat-sitters` на трёх ширинах; профили обеих ролей и чат — на 360 px. **0 обнаруженных нарушений в этих прогонах**. Это автоматическая проверка выбранных состояний, а не сертификация полной доступности. Исправлены контраст ссылок, начальный фокус и гонка cookie/CSRF при двойном эффекте StrictMode.

## Безопасность зависимостей и границы приёмки

CRA, устаревшая Redux-обвязка и лишние пакеты заменены Vite/Context. Один workspace lock обеспечивает воспроизводимость. Для CommonJS Sequelize задан ограниченный override `uuid ^11.1.1`; установка и реальные CRUD/транзакции после него проверены. Не применялся `npm audit fix --force`. Sequelize 6 сохранён ради совместимости старых моделей/миграций; его deprecated `dottie` нужно отслеживать при следующем обновлении ORM.

Проверка истории по шаблонам приватных ключей, GitHub/AWS-токенов не обнаружила совпадений. Старые env-файлы содержали пустые шаблоны, они удалены из актуального дерева; реальные `.env`/test URL не коммитятся. Такой поиск не доказывает отсутствие любого секрета и не заменяет специализированный аудит.

Не выполнены: эксплуатационная нагрузка, Linux/WSL runtime, реальный production TLS/reverse proxy, браузеры Firefox/Safari, ручной screen-reader аудит, инфраструктурный backup/restore, несколько API-реплик. GitHub Actions не создавались; результаты выше получены локально, это не статус внешнего CI. Следующий DevOps шаг описан в [DEVOPS_HANDOFF](DEVOPS_HANDOFF.md).
